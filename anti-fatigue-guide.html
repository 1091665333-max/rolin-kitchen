抗疲劳饮食指南

功能医学视角 · 饮食干预方案

疲劳不是「累了睡一觉就好」。在功能医学中，慢性疲劳是 ATP（细胞能量货币）的供需持续失衡——休息后不能充分恢复，能量表始终停在 40-60%。这份指南帮助你识别疲劳类型，并给出每种类型的具体饮食策略。

一、你的疲劳是哪一种？

选最像你的 1-2 个描述。大多数人混合了 2-3 种，选最困扰你的那个作为主攻方向。

A
HPA 轴型
早晨最累，下午稍好一点但从来不真正恢复，靠咖啡续命
B
线粒体型
什么事都不做也累，稍微动一下更累，恢复极慢，肌肉酸痛
C
炎症/免疫型
疲劳像在感冒——肌肉酸、喉咙不舒服、低烧感，持续几个月
D
神经递质型
不是身体不能动，是心里没有「想去做」的动力，对什么都提不起兴趣
E
代谢/血糖型
饭后特别困，不吃就心慌手抖，特别想吃甜食和碳水

二、五种疲劳类型的饮食策略

A 型：HPA 轴疲劳——「充电器坏了」

在功能医学中发生了什么：
长期面临慢性压力，会打乱肾上腺皮质醇的正常节律。具体表现为：早晨本该升高的皮质醇无法正常上升，让人早上很难起床；而到了夜间本该降低的皮质醇又迟迟降不下来，从而引发入睡困难和半夜醒来。这实际上意味着，负责身体能量动员的 HPA 轴总开关出现了"卡壳"。

饮食策略：稳住血糖 + 补肾上腺原料

原则具体做法
绝不空腹喝咖啡咖啡因 → 皮质醇脉冲。先吃早餐再喝，或改在上午 10 点后
早餐必吃，起床 1 小时内给 HPA 轴一个「天亮了、有燃料了」的信号
每餐蛋白 ≥20g稳定血糖，减少肾上腺救急脉冲
睡前防低血糖如果半夜醒，睡前一小块慢碳+蛋白

核心营养素 + 高含量食物

营养素为什么吃什么
维生素 C肾上腺是全身 VC 浓度最高的组织，慢性压力→VC 消耗↑猕猴桃、红甜椒、西兰花、针叶樱桃
维生素 B5辅酶 A 前体→胆固醇→皮质醇合成的第一步牛肝、葵花籽、香菇、牛油果、鸡蛋
镁支持 GABA 系统 → 抑制 HPA 过度激活南瓜籽、杏仁、黑巧克力、菠菜
维生素 B12 + 叶酸甲基化循环 → 肾上腺素合成蛤蜊、动物肝脏、深绿色叶菜

B 型：线粒体疲劳——「发电厂本身坏了」

在功能医学中发生了什么：
当线粒体电子传递链的五个复合体中，只要有一个效率下降，就会导致 ATP 产出不足。这通常由 B 族辅因子不足、辅酶Q10合成下降、心磷脂被活性氧氧化，或者是线粒体 DNA损伤积累所引起。最终的结果就像身体的电池容量变小了，只要稍微有一点消耗，就需要很长的时间才能恢复。

饮食策略：给 ETC 每一步补辅因子 + 抗氧化保护线粒体膜

原则具体做法
B 族全谱覆盖TCA 循环和 ETC 的每一步都至少有一个 B 族做辅酶
抗氧化全层防御VE（膜）+ VC（细胞质）+ 硒（线粒体 GPX）三层防线
足量 CoQ10 前体CoQ10 将电子从复合体 I/II 传到 III，关键瓶颈

C 型：炎症/免疫型疲劳——「疾病行为关不掉」

在功能医学中发生了什么：
身体在初次触发病毒感染后，免疫系统会激活表现为疲劳、嗜睡和社交回避的"疾病行为"程序。这个程序本该在感染清除后自动关闭，但实际上却没有关上，从而导致白介素-1β和肿瘤坏死因子-α持续处于低度释放状态。接着，干扰素-γ会持续激活 IDO，使得色氨酸被大量分流到了犬尿氨酸代谢通路中。这一改变直接导致体内 5-羟色胺和褪黑素减少，同时产生了具有 NMDA 兴奋毒性的喹啉酸。最终，无论是疲劳、情绪低落、脑雾还是睡眠差，全都是由这条被劫持的色氨酸通路引起的。

饮食策略：促消退（不只是抗炎）+ 减少色氨酸被盗

原则具体做法
EPA/DHA 优先提供 SPM 消退介质前体 → 发出「炎症可以结束了」的信号
多酚抗炎谱每餐 ≥3 种颜色的蔬菜水果，多靶点抑制 NF-κB
槲皮素稳定肥大细胞膜 → 减少组胺和炎症介质释放
低组胺饮食试用如果合并过敏/荨麻疹/鼻炎，4 周低组胺饮食

D 型：神经递质型疲劳——「没有火花」

在功能医学中发生了什么：
多巴胺水平下降，让人无法从日常活动中获得期待或愉悦，从而导致缺乏驱动力；去甲肾上腺素水平下降，使人难以维持警觉状态；乙酰胆碱水平下降，则会影响记忆和注意力的维持。这并不是因为懒，而是神经递质合成链条的某个环节卡住了。具体来说，从酪氨酸到左旋多巴、多巴胺再到去甲肾上腺素的这条通路，需要铁、维生素B6、锌、铜和维生素C作为辅因子；而从色氨酸到5-羟色胺的通路，则需要铁、维生素B6和维生素B3来作为辅因子。

饮食策略：提供神经递质前体 + 所有辅因子

原则具体做法
早餐高蛋白提供酪氨酸（DA/NE 前体）和色氨酸（5-HT 前体）
铁 + B6 + 锌 + 铜 全配齐四个辅因子缺一个，酪氨酸羟化酶（DA 合成限速酶）就卡住
鸡蛋不能丢胆碱 → 乙酰胆碱（ACh）的前体

酪氨酸DA + NE + 肾上腺素的前体鸡胸肉、牛肉、三文鱼、鸡蛋、奶酪
铁酪氨酸羟化酶（DA 合成限速酶）辅因子动物肝脏、蛤蜊、牛肉
B6DOPA 脱羧酶 → L-DOPA → DA鹰嘴豆、金枪鱼、鸡胸肉、香蕉、土豆

胆碱→ 乙酰胆碱（ACh）鸡蛋（蛋黄）、牛肝、三文鱼

E 型：代谢/血糖型疲劳——「富饶中的饥荒」

在功能医学中发生了什么：
出现胰岛素抵抗时，葡萄糖转运蛋白 4无法正常转位，导致葡萄糖虽然留在血液中却进不去细胞，使肌肉和大脑的线粒体陷入了能量饥荒。由于胰岛素第一时相减弱，饭后血糖会迅速冲高；随后，胰岛 β 细胞在第二时相进行超额且延迟的分泌，这就造成了餐后 2 到 4 小时血糖的过度回落，引发低血糖。面对低血糖，身体会紧急分泌肾上腺素和皮质醇来救急，从而让人出现心慌、手抖和烦躁等症状，并产生对碳水化合物的强烈渴望。为了缓解这种不适，人往往会忍不住去吃东西，从而陷入下一轮血糖过山车。这种反复出现的低血糖脉冲，会在数月到数年的时间里持续消耗肾上腺，最终导致 HPA 轴耗竭。

饮食策略：削平血糖过山车

原则具体做法
进食顺序先吃菜 → 再吃蛋白 → 最后吃碳水（降低餐后血糖峰值 30-40%）
每餐蛋白 ≥25g + 纤维 ≥8g蛋白 + 纤维双屏障延缓胃排空和葡萄糖吸收
碳水 GI 控制在 50 以下薯类、燕麦、藜麦、豆类替代白米白面
肉桂 + 醋肉桂改善胰岛素信号效率；醋延缓胃排空、抑制α-淀粉酶

核心营养素 + 高含量食物

营养素为什么吃什么
铬增强胰岛素受体信号 → 改善 GLUT4 转位西兰花、全谷物、牛肉、啤酒酵母
镁胰岛素受体酪氨酸激酶活性需要 Mg-ATP南瓜籽、杏仁、菠菜
硫辛酸直接改善胰岛素敏感性 + 抗氧化动物肝脏、菠菜、西兰花
肉桂延缓胃排空 + 改善胰岛素信号肉桂粉（每日 1/2-1 小勺）
纤维物理屏障延缓葡萄糖吸收燕麦、豆类、薯类带皮吃

三、通用抗疲劳饮食七原则

不管你的主导类型是什么，这七条对所有人都适用。

#原则一句话解释
1每餐蛋白 ≥20g蛋白质不是「增肌用的」——在抗疲劳中，它是血糖稳定剂+神经递质前体+组织修复原料
2颜色越多越好每种颜色提供不同的多酚组合 → 在不同靶点抑制炎症
3先吃菜再吃碳水一个免费的餐后血糖减峰策略
4深海鱼每周 ≥3 次EPA/DHA 不仅是抗炎，更是促消退——发出「炎症可以结束了」的信号
5戒断加工食品和甜饮料高果糖→肝脂肪堆积；AGEs→氧化应激↑；乳化剂→肠道屏障损伤
6水喝够脱水状态下，血容量↓ → 心脏做功↑ + 脑灌注↓ → 疲劳的主观体验被放大
7早餐必吃，睡前 3 小时吃完晚餐给 HPA 轴和你自己的消化系统一个明确的节律锚点

六、不要做的事

和吃一样重要。

#不要原因
1空腹喝咖啡皮质醇脉冲 → HPA 轴已经在被过度使用
2下午 3 点以后喝咖啡咖啡因半衰期 5-6 小时 → 晚上 9 点还有一半在系统里 → 干扰入睡
3晚餐太晚或太重消化系统加班 → 核心体温不降 → 睡眠质量打折
4单吃碳水甜食/白面包/白米饭单吃 → 血糖尖峰 → 胰岛素超额 → 血糖骤降 → 疲劳反弹
5白天长时间不进食超过 4-5 小时不吃 → 血糖下降 → 皮质醇上升 → 肾上腺被反复消耗
6睡前刷手机蓝光抑制褪黑素 → 你的入睡困难有一部分是屏幕驱动的
7高强度运动如果你的疲劳是线粒体型，剧烈运动后恢复极慢 → 先走路，别跑
